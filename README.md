## About the Project

Flappy Bird is a browser-based arcade game inspired by the classic Flappy Bird gameplay.

The objective is simple: control the bird, avoid obstacles, and survive as long as possible while earning points.

This project demonstrates the use of JavaScript game logic, keyboard interactions, collision detection, and basic animations.

## Features

- Classic Flappy Bird-inspired gameplay.
- Keyboard-based bird controls.
- Obstacle generation and movement.
- Collision detection.
- Real-time score tracking.
- Sound effects for scoring and game over.
- Custom bird and background graphics.
- Lightweight browser-based gameplay.

## Tech Stack

- **HTML5** – Game structure.
- **CSS3** – Styling and layout.
- **JavaScript** – Game mechanics and interactions.
- **Audio** – Sound effects.

## How to Play

1. Clone the repository:

   ```bash
   git clone https://github.com/ShivangVShukla/Flappy-Bird-Game.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Flappy-Bird-Game
   ```

3. Open `index.html` in your browser.

4. Use the keyboard controls to make the bird fly and avoid the pipes.

5. Try to achieve the highest possible score!
